# Background Music

Place your chosen music file here as:

    src/assets/audio/nikkah-music.mp3

No file is bundled with this project — you must supply your own
royalty-free / licensed track (Nasheed, instrumental, or any music you
have the rights to use). Good royalty-free sources includes:

- Your own licensed purchase (Envato Elements, Artlist, Soundstripe, etc.)
- Nasheed artists who explicitly permit free use with attribution
- Royalty-free instrumental libraries (YouTube Audio Library, Pixabay Music)

Once the file is in place at the path above, everything else (looping,
fade-in, play/pause control) works automatically — no code changes needed.

If no file is present, the site will not throw an error; the "Tap to Open"
interaction will simply have no audio, and the floating music control will
indicate playback is unavailable.
